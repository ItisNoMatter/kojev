# kojev

A Kotlin Multiplatform client library for **Jev**, TypeSafe AI's System One model.

Answers to Jev questions come back as the caller's own `enum` / `sealed` types, typed end to end,
instead of a string key to look up and cast.

## Status

This library does not work yet. It is under active early-stage development and has no
released artifacts. See `docs/bootstrap.md` for the development phases.
